## The other modules

Modules 2–9 end with self-check questions that are deliberately **open** — they ask about
*your* organisation, and there is no single correct answer. Use them as discussion prompts.
The material needed to answer each one is in the module's own sections; the question numbers
map to the section order.

Trainers: the **Instructor notes** block at the foot of every lab README carries the expected
duration, the three failures that actually occur in the room, and a debrief question.
